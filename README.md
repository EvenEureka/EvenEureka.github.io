# Yiwen Lu

Personal academic website: https://eveneureka.github.io/

## Current website

The current website is a static HTML, CSS, and JavaScript site in `docs/`.
GitHub Pages publishes the `master` branch, `/docs` directory.

- `docs/index.html`: profile, research, publications, teaching, and beyond research
- `docs/styles.css`: layout and responsive styles
- `docs/site.js`: theme switch, publication filters, and portrait interaction
- `docs/assets/`: photos, fonts, CV, and lecture slides

To preview locally, run `python3 -m http.server 8765 --directory docs` and open http://localhost:8765/.
Commit updates to `master` to publish them automatically.

The earlier Academic Pages template remains outside `docs/`, with its history and license preserved.
